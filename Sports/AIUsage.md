### Usage of AI for development

**Integrating retries:**
Used AI to integrate retries when the external API call fails or publishing message to kafka broker fails
and recovery mechanism in case specified number of retries fail

**Integrating Unit Tests:**
I gave AI the code and the different happy and unhappy cases in plain english, it generated the code for those 
testcases

**Debugging code while testing**
Whenever i faced an error, maybe on application startup, or publishing message to kafka anything i used AI to understand that error and do the necessary code fixes

### My changes over AI suggestions in development
**Enum usage:** Usage of enums in the POJOs instead of string objects to code readability and maintainability

**Integrating SRP:** Integrating Single Responsibility Principle at Service and Config Layer defining one service has only one responsibility. Eg APIClientService only has the purpose of calling external APIs.
