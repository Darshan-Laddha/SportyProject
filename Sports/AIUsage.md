### Usage of AI for development

1. **Integrating retries:**
Used AI to integrate retries when the external API call fails or publishing message to kafka broker fails
and recovery mechanism in case specified number of retries fail


2. **Integrating Unit Tests:**
AI helped in UT generation provided the code and the different happy and unhappy cases in plain english.


3. **Debugging code while testing**
Debugging errors on application startup, or publishing message to kafka anything i used AI to understand that error and do the necessary code fixes

### My changes over AI suggestions in development
1. **Enum usage:** Usage of enums in the POJOs instead of string objects to code readability and maintainability


2. **Integrating SRP:** Integrating Single Responsibility Principle at Service and Config Layer defining one service has only one responsibility. Eg APIClientService only has the purpose of calling external APIs.
